## 📌 About This Project

This repository contains the code and materials from my first learning session where I built a simple To-Do application using basic Python concepts. The session focused on practical implementation and understanding core Python fundamentals through a real project.

## 🎯 Session Objectives

- Learn Python basics through hands-on coding
- Build a functional To-Do application
- Understand fundamental programming concepts
- Practice problem-solving with real-world scenarios

## 🚀 What I Built

A feature-rich command-line To-Do application with priority-based task management:
- ➕ **Add Tasks** with name, priority (High/Medium/Low), and category
- 📋 **View Tasks** sorted by priority (High → Medium → Low)
- ✅ **Complete Tasks** and move them to completed list
- 👁️ **View Completed** tasks with full details
- 🗑️ **Remove Tasks** from active list
- 🧹 **Clear All** tasks at once
- 🚪 **Exit** application gracefully

## 🛠️ Technologies Used

- **Python 3.x** - Core programming language
- **Nested Lists** - Task storage with [name, priority, category] structure
- **List Operations** - append(), remove(), clear() methods
- **Control Flow** - while loops, if/elif/else statements
- **Functions** - Custom sorting and menu display
- **String Formatting** - f-strings for clean output display

## 📚 Python Concepts Covered

- **Data Structures**: Lists and nested lists
- **Functions**: Custom function creation (menu(), sort_list())
- **Loops**: while loops for menu system, for loops for iteration
- **Conditionals**: if/elif/else for menu choices
- **List Methods**: append(), remove(), clear(), len()
- **User Input**: input() function with type conversion
- **String Formatting**: f-strings for dynamic output
- **Priority Sorting**: Custom sorting algorithm by priority levels
